# Namma-Skill 🚀

Namma-Skill is a Skill Development & Training Opportunity Tracker App designed to help rural youth discover vocational training programs and self-employment opportunities.

## 📌 Features

* Firebase Authentication (Login/Register/Forgot Password)
* Course Discovery & Search
* Favorites System ❤️
* Candidate Application Workflow
* Real-time Status Tracking
* Admin Dashboard
* Notifications & Alerts
* Success Stories Section
* Modern Jetpack Compose UI
* Room Offline Database
* Firebase Firestore Backend

## 🛠 Tech Stack

* Kotlin
* Jetpack Compose
* Firebase Authentication
* Firebase Firestore
* Room Database
* MVVM Architecture
* Material 3

## 📱 Modules Implemented

* Authentication Module
* Course Management
* Application Tracking
* Admin Approval System
* Favorites Management
* Profile Dashboard
* Notifications Screen

## ▶️ How to Run

1. Clone the repository
2. Open project in Android Studio
3. Sync Gradle files
4. Add Firebase `google-services.json`
5. Run the application on emulator or Android device

## 🎯 Objective

The main objective of this project is to empower rural youth by providing digital access to skill training programs, employment opportunities, and vocational development resources.
